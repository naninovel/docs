开发者信赖的引擎

Naninovel 是一套用于互动叙事的一体化工具套件，自 2018 年起每年发布新版本，持续进化。

为作者设计的脚本

使用 NaniScript 在文本文档中编写故事，或在可视化的故事编辑器中创作，无需编程。分支、变量和条件全部内置。

开箱即用

完整的 UI、存档与读档、状态回滚、历史记录、本地化、自动配音、CG 画廊、对话触发器等数十个系统均已内置，即刻可用。

久经考验

已在 PC、主机和移动平台发布的数百款作品中经受实战考验。从独立创作者到发行商，Naninovel 是各种规模工作室的行业标准。

适用于任何游戏

Naninovel 既可以用作视觉小说模板，也可以启用对话模式并集成到现有项目中，为任何类型的游戏添加分支对话和过场动画。

专业服务

优先支持、源代码访问、基于 GitHub 的安装以及 LTS 发布流。许可证包含 1 年的支持计划，并可永久获取所有后续版本。

完全可定制

每项内置功能都可以通过简单调整预制件或简洁的 C# API 来扩展、覆盖或替换，引擎架构从设计之初就是模块化的。
