# サポート

サポートが必要なときは、まず公式Discordサーバーをご利用ください：[discord.gg/BfkNqem](https://discord.gg/BfkNqem)。

`#forum` チャンネルでは質問や相談ができ、`#wiki` ではチュートリアルやガイドを探せます。`#chat` で他のNaninovelユーザーとの雑談もお楽しみください。

有効な [サポートプラン](/ja/support/#サポートプラン) をお持ちの場合は、Naninovelチームが直接対応する `#support` チャンネルも利用できます。[ライセンスを登録](https://account.naninovel.com) すると、最初の1年間はサポートプランを無料で利用できます。

## サポートプラン

サポートプランでは、Discordサーバーでの専用サポートをはじめ、次のサービスを利用できます。

- `#support` チャンネルでの技術的な問題やトラブルシューティングリクエストに対するチームからの優先対応
- Naninovelのコードベース全体に精通したサポートボット、Nani-kunによる即時回答
- 開発プロセスを追跡できるGitHub上のエンジンのソースコードリポジトリへのアクセス
- 最新のプレビューおよび安定リリースブランチを含むUPMリポジトリへのアクセス（GitHubから直接Naninovelをインストールおよび更新可能）

[ライセンスを登録](https://account.naninovel.com) すると、1年間の無料サポートプランが付属します。その後は、[アカウントダッシュボード](https://account.naninovel.com/support) からいつでもサブスクリプションを更新できます。

::: info NOTE
サポートプランへの加入は任意です。加入していなくても、[ダウンロードアーカイブ](https://account.naninovel.com/download) から、今後のすべてのNaninovel安定リリースを引き続き無期限で入手できます。`#forum` チャンネルでのコミュニティサポートも継続して利用でき、いつでも質問や相談ができます。
:::

## バグの報告

何かが意図したとおりに機能していないと思われる場合は、[Discord](https://discord.gg/BfkNqem) の `#support` チャンネル（有効な [サポートプラン](/ja/support/#サポートプラン) をお持ちの場合）または `#forum` チャンネルでお知らせください。

報告する前に、以下を行ってください。

- 問題が発生している機能またはユースケースについて、[ガイド](/ja/guide/)、[コマンドリファレンス](/ja/api/)、および [よくある質問](/ja/faq/) を確認してください。何かを見落としている可能性が高いためです。
- 利用可能な最新のNaninovelバージョンを使用していることを確認してください。最新のパッチは [UPMリポジトリ](/ja/guide/getting-started#githubからインストール) から入手できます。アセットストアやダウンロードアーカイブで配布されているパッケージには、最新のパッチが含まれていないことがよくあります。
- 最近、以前のNaninovelリリースからアップグレードした場合は、[リリースノート](/releases/) のアップグレード手順に必ず従ってください。
- プロジェクトルートの「Library」フォルダーを削除してエディターを再起動し、Unityのキャッシュをクリアしてみてください。
- 問題の原因がNaninovelにあり、他のサードパーティプラグインやUnity自体ではないことを確認してください。Unityが原因の場合は、[Unityサポートにお問い合わせください](https://unity.com/support-services)。

バグを報告するときは：

- 問題の内容と、再現するまでの手順を明確かつ簡潔に説明してください。
- Naninovelのバージョン、Unityのバージョン、ターゲットプラットフォーム（Android、iOS、WebGLなど）、使用しているOS（Windows、macOS、Linux）を記載してください。
- 関連するエラーや警告を含む [ログファイル](https://docs.unity3d.com/Manual/LogFiles.html) を添付してください。

## 再現プロジェクト

問題を報告する際、それを再現する小さなUnityプロジェクトの提供を求められる場合があります。
再現プロジェクトは、問題を示すために必要な**最小限の**変更のみを含む**新しいクリーンなUnityプロジェクト**である必要があります。

以下の手順に従ってください。

1. 新しいUnityプロジェクトを作成します。[サポートされているUnityバージョン](/ja/guide/compatibility#unityバージョン) を使用していることを確認してください。
2. 利用可能な最新のNaninovelバージョンをインストールします。パッケージフォルダー内では何も変更・追加しないでください。変更されたバージョンのパッケージはサポートできません。
3. 問題を再現するために必要なアセットとスクリプトを追加します。既存のプロジェクト全体をコピーしないようにしてください。まっさらな状態から始めて、問題だけを切り分けて再現してください。サードパーティのプラグインや不要なコンテンツは避けてください。
4. プロジェクトルートに `repro.txt` ファイルを作成し、再現手順と、期待する結果・実際の結果の簡潔な説明を記述します。例：
    ```
    1. シーン「Assets/Scenes/SampleScene」を開く。
    2. エディターでプレイモードに入る。
    3. 新しいゲームを開始する。
    4. 15行目までプレイする。
    5. ゲームをセーブしてロードする。

    期待される結果：音楽「Ambient」が再生されるはず。
    実際の結果：音楽が再生されない。
    ```
5. プロジェクトサイズを小さくするために「Library」フォルダーを削除し、プロジェクトフォルダーをzip圧縮します。
6. 再現プロジェクトを要求したNaninovelチームメンバーにDiscordのDMを通じて非公開で共有してください。個人的なアセットや著作権で保護されたアセットが含まれている可能性があるため、公開チャンネルでプロジェクトを共有しないでください。
