# ボイス

ボイスクリップをエンジンに公開するには、それらを `Resources/Naninovel/Voice` フォルダー（オーディオ構成の `Voice Loader` フォールドアウトで変更可能）の下に保存します。必要に応じて、さらにサブフォルダーで整理することもできます。この場合、シナリオスクリプトで参照するときはスラッシュ（`/`）を使用します。たとえば、`Resources/Naninovel/Voice/Intro/Day/25.wav` として保存されているボイスオーディオクリップは、スクリプトで `Intro/Day/25` として参照できます。

[Addressable Asset System](/ja/guide/resource-providers#手動割り当て) を使用してリソースを手動で公開することも可能です。詳細についてはガイドを参照してください。

ボイスクリップには、[Unityでサポートされている](https://docs.unity3d.com/Manual/AudioFiles.html) 任意のオーディオ形式を使用できます。

ボイス再生の動作は、`Naninovel -> Configuration -> Audio` エディターメニューを使用して構成できます。利用可能なオプションについては、[構成ガイド](/ja/guide/configuration#オーディオ) を参照してください。

シナリオスクリプトでボイスを再生するには、[@voice] コマンドに続けてクリップ名（パス）を指定します。例：

```nani
@voice Hello
```

— `Resources/Naninovel/Voice/Hello.wav` に保存されているボイスクリップアセットを再生します。

::: info NOTE
[@voice] コマンドは、特定の瞬間にボイスクリップを時々再生することを目的としており、完全なボイスオーバーの実装には適していません。ほとんどのテキスト行にボイスクリップが関連付けられているプロジェクトでのボイス処理方法の詳細については、以下の「オートボイス」セクションを参照してください。一部の組み込み機能（バックログでのボイスリプレイ、ボイスオーバードキュメントなど）は、オートボイスワークフローでのみ機能します。
:::

## オートボイス

フルボイスのゲームでは、ボイスのある行ごとに [@voice] コマンドを指定するのは面倒になる可能性があります。オートボイス機能を使用すると、ボイスのあるテキスト行の一意の識別子に関連付けられたボイスクリップを自動的に再生できます。オートボイスを有効にするには、オーディオ構成メニューの `Enable Auto Voicing` トグルを有効にします。

ボイスオーディオクリップをボイスのあるテキスト行に関連付けるには、ボイスマップユーティリティを使用するか、UnityのAddressable Asset Systemでオーディオクリップアセットにアドレスを割り当てます。別の [リソースプロバイダー](/ja/guide/resource-providers) にアセットを公開する方法もあります。

オートボイスが有効になっている場合、オーディオ構成メニューに「Open Voice Map Utility」ボタンが表示されます。`Naninovel -> Tools -> Voice Map` エディターメニューからもユーティリティにアクセスできます。

![](https://i.gyazo.com/3c8fad99f7a18e3f0eaf419c9be92277.mp4)

まず、ボイスクリップをマップするスクリプトファイルを選択します。選択したスクリプトにprintコマンド（または汎用テキスト行）が含まれている場合は、オーディオクリップフィールドとペアで一覧表示されます。フィールドにボイスクリップをドロップ（または選択）して、テキストに関連付けます。クリップを自動マップすることも可能です。これを行うには、ボイスのある行のテキストの冒頭と一致するようにクリップアセットに名前を付け、クリップ（またはそれらを含むフォルダー）をボイスマップユーティリティにドラッグします。

::: warning
ボイスマップウィンドウを介してクリップを割り当てる場合は、競合を防ぐために、ボイスクリップはどの「Resources」フォルダーにも含まれない場所に保存してください。
:::

クリップを割り当てる前に、`Locale` フィールドで[ボイス言語](/ja/guide/voicing#ボイス言語)を選択します。初期値はソースロケールです。別のロケールを選ぶと、[スクリプトローカライズドキュメント](/ja/guide/localization#スクリプトのローカライズ)のテキストが表示されます。翻訳がない場合や空の場合は元のテキストが表示されますが、クリップは選択したロケールに割り当てられます。

同じ話者に同一のテキストメッセージが（同じスクリプト内に）ある場合、両方のメッセージが同じボイスクリップに関連付けられます。これが望ましくない場合は、どちらかのメッセージに一意のテキスト識別子を追加します。例：

```nani
こんにちは。
こんにちは。|#uniqueid|
```

::: tip
エディターメニューの `Naninovel -> Tools -> Text Identifier` を使用すると、ボイスのある行を含むすべてのローカライズ可能なスクリプトテキストに対して、Naninovelに一意のIDを自動生成させることができます。これにより、重複する行にIDを手動で割り当てる必要がなくなり、すでにマップされた行を編集しても関連付けが壊れることはありません。詳細については、[テキスト識別](/ja/guide/scenario-scripting#テキスト識別) を参照してください。
:::

ボイスマップユーティリティを使用せずにクリップを関連付けるには、テキストIDの前にスクリプトパスとボイスローダープレフィックス（デフォルトでは `Voice`）を付け、それをリソース名としてアセットをリソースプロバイダーに公開します。特定のボイスのある行のスクリプトパスとテキストIDを調べるには、[ボイスオーバードキュメント](/ja/guide/voicing#ボイスオーバードキュメント) を使用します。たとえば、パスが `Script01` のスクリプト内で、テキストIDが `2670eb4` の行にボイスを関連付ける場合、Addressableリソースプロバイダーで次のアドレスを使用します：`Naninovel/Voice/Script01/2670eb4`。

ゲームの実行中に現在表示されているテキストに関連付けられたオートボイスIDを見つけるには、デバッグウィンドウを使用します。

![auto voicing](https://i.gyazo.com/12772ecc7c14011bcde4a74c81e997b8.png)

ウィンドウを表示するには、エンジン構成で `Enable Development Console` がオンになっていることを確認し、プレイモード中に `~` キーを押し、`debug` と入力して `Enter` を押します。

::: tip EXAMPLE
[オートボイスサンプル](/ja/guide/samples#オートボイス) で、複数のロケール向けにオートボイスをセットアップする例を確認できます。
:::

## 話者の音量

オートボイスを使用する場合、特定の [キャラクター](/ja/guide/characters)、より正確には表示されるテキストメッセージの話者のボイス音量をプレイヤーが制御できるようにしたい場合があります。たとえば、プレイヤーが主人公のボイスをミュートしたり、特定のキャラクターのボイスを小さくしたりしたいと考えるかもしれません。

話者ごとのボイス制御をセットアップするには、[カスタム設定UIを作成](/ja/guide/gui#組み込みuiの変更) し、新しいスライダーを追加し（プレハブにすでにある「VoiceVolumeSlider」を複製できます）、`Author IDs` リストに話者（キャラクター）IDを追加します。

![](https://i.gyazo.com/5a8db32ca5d971f2876f71d35f1a020c.png)

追加されたスライダーは、指定されたキャラクターのボイス音量を制御するようになります。1つのスライダーで複数の話者を制御するには、リストにIDを追加します。たとえば、キャラクターの心の声を別のIDの話者として表示している場合などです。リストが空の場合、スライダーはオーディオミキサーのボイスグループの音量を制御し、すべてのボイスに影響します。

## ボイス言語

異なるローカライズ用のボイスオーバーを追加する場合、メインのローカライズとは独立して、プレイヤーがボイス言語を選択できるようにすることが可能です（例：テキストとUIは英語で、ボイスオーバーは日本語でゲームをプレイする）。

ゲーム設定にボイス言語ドロップダウンを追加するには、オーディオ構成メニューで `Voice Locales` プロパティを割り当てます。対応するボイスリソースがあるロケールの言語タグを追加します。たとえば、以下の例では、プレイヤーが英語と日本語のボイスから選択できるようになります。

![](https://i.gyazo.com/904a59d1a18510373da97bc9b26e8880.png)

プロパティが割り当てられると、ゲーム設定メニューに「Voice language」ドロップダウンが表示されます。

![](https://i.gyazo.com/70382bb24637a4d8846c3b65f1ea01d9.png)

ゲームリソースのローカライズ方法の詳細については、[ローカライズガイド](/ja/guide/localization) を参照してください。

## ボイスオーバードキュメント

ボイスオーバードキュメントは、ボイスオーバーオーディオの制作時にボイス収録エンジニアや声優が使用するためのものです。

`Naninovel -> Tools -> Voiceover Documents` からアクセスできるボイスオーバードキュメント生成ユーティリティを使用して、[@print] コマンドと汎用テキスト行で表示されるテキストを含むドキュメントを生成します。表示される各テキストメッセージには、オートボイスIDが関連付けられます。

![](https://i.gyazo.com/d1e40ff118daebd83b55e0433431b2a8.png)

`Locale` で出力するテキストの言語を選択します。初期値はソースロケールです。翻訳がない場合や空の場合は元のテキストが使われます。ドキュメントの生成に Play モードは不要で、実行中のゲームのロケールも変更されません。

`Format` プロパティは、生成するボイスオーバードキュメントのファイルタイプとフォーマットを制御します。

- Plaintext — フォーマットなしのプレーンテキストファイル。
- Markdown — 読みやすくするための追加のフォーマットを備えた [Markdown](https://en.wikipedia.org/wiki/Markdown) ファイル。
- CSV — GoogleスプレッドシートやMicrosoft Excelなどの表計算ソフトで使用される [カンマ区切り値](https://en.wikipedia.org/wiki/Comma-separated_values) ファイル。

### カスタムジェネレーター

ドキュメントを特別な方法でフォーマットおよび/またはシリアル化したい場合は、カスタムボイスオーバードキュメントジェネレーターを注入することが可能です。

カスタムジェネレーターを追加するには、パラメーターなしのコンストラクターを持つ新しいC#クラスを作成し、`IVoiceoverDocumentGenerator` インターフェースを実装します。ユーティリティはそのようなクラスを自動的に検出し、組み込みジェネレーターの代わりに使用します。

ユーティリティは、登録されたシナリオスクリプトごとに `GenerateVoiceoverDocument` を呼び出します。`list` はスクリプトのコマンド一覧、`locale` は出力言語、`outDir` は選択した出力ディレクトリです。選択した言語のテキストを取得するには、`LocalizableTextResolver.Resolve(cmd.Text, locale)` を使用します。

以下は、スクリプトパスとロケールを含むヘッダーを追加し、その後にスクリプト内で見つかった各printコマンドに対して `auto-voice id > author > text` 行を追加するカスタムボイスオーバージェネレーターの例です。

```cs
public class VoiceoverGenerator : IVoiceoverDocumentGenerator
{
    public void GenerateVoiceoverDocument (ScriptPlaylist list, string locale, string outDir)
    {
        var builder = new StringBuilder();
        builder.AppendLine($"Voiceover for '{list.ScriptPath}' ({locale} locale)");
        foreach (var cmd in list.OfType<PrintText>())
        {
            var voiceId = AutoVoiceResolver.Resolve(cmd.Text);
            var text = LocalizableTextResolver.Resolve(cmd.Text, locale);
            builder.AppendLine($"{voiceId} > {cmd.AuthorId} > {text}");
        }
        var path = Path.Combine(outDir, $"{list.ScriptPath}.txt");
        Directory.CreateDirectory(Path.GetDirectoryName(path));
        File.WriteAllText(path, builder.ToString());
    }
}
```
