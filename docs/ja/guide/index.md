# はじめに

Naninovelは [Unityゲームエンジン](https://unity.com) の拡張機能で、シナリオライター向けの制作ツール群と開発者向けのC#フレームワークを提供します。ゲーム内の会話やカットシーンから本格的な [ビジュアルノベル](https://en.wikipedia.org/wiki/Visual_novel) まで、物語を中心としたコンテンツの制作を効率化するために設計されています。

![](https://www.youtube.com/watch?v=lRxIKDU9z4k)

::: info NOTE
NaninovelはUnityで実現できることを制限しません。ただし、一部の組み込み機能を正しく動作させるには、対応するUnityバージョン、プロジェクト構成、ターゲットプラットフォームなどの要件を満たす必要があります。詳細は [互換性ページ](/ja/guide/compatibility) を参照してください。
:::

このオンラインドキュメントは、エンジンの変更に合わせて更新される公式の主要リファレンスです。シナリオライターは [スタートガイド](/ja/guide/getting-started) と [シナリオスクリプト](/ja/guide/scenario-scripting) ガイドから読み始めてください。開発者には「開発者」セクションもお勧めします。「アドバンスド」セクションではC#フレームワークを扱います。Naninovelを既存のコードベースに統合する場合や、より踏み込んだ拡張・カスタマイズを行う場合に参照してください。

特定のトピックを探すときは、サイト上部の検索バーを使ってみてください。頻繁に寄せられる質問への回答は [よくある質問](/ja/faq/) に、標準のスクリプトコマンドと使用例は [APIリファレンス](/ja/api/) にまとめています。必要な情報が見つからない場合は、お気軽に [サポートにお問い合わせください](/ja/support/)。
