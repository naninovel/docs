# カスタムアクターシェーダー

ほとんどのキャラクターおよび背景アクター（汎用を除く）をレンダリングする際には、半透明のオーバードローを処理し、さまざまなトランジションエフェクトをサポートするために、特別なシェーダーが使用されます。

アクター構成メニューにある `Custom Texture Material` プロパティにマテリアルを割り当てることで、デフォルトのシェーダーをオーバーライドできます。

![](https://i.gyazo.com/8b6c06d2a7ed276f17cb25ecf7bcc4b0.png)

割り当てられたマテリアルで使用されるシェーダーには、特定のプロパティが必要であることに注意してください。参考のために、`Naninovel/Resources/Naninovel/Shaders/TransitionalTexture` にあるデフォルトのシェーダーを確認してください。

アクターがシーン内でスプライトとして表現される場合は、`Custom Sprite Material` プロパティが利用可能です（テクスチャにレンダリングされない非汎用実装がこれに該当します）。デフォルトでは、ライティングなし（Unlit）のシンプルな透過シェーダーが使用されます。ライティングやサーフェス効果を実装したい場合は、カスタムシェーダーを持つマテリアルをこのプロパティに割り当てます。

::: tip EXAMPLE
[アクターシェーダーサンプル](/ja/guide/samples#アクターシェーダー) では、カスタムトランジションエフェクトを追加するテクスチャシェーダーの作成方法と使用方法を紹介しています。また、ライティングと自己発光をサポートするスプライトシェーダーを作成し、背景アクターで時間帯を表現する例もあります。
:::
